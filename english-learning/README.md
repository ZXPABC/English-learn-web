# 轻松学英语 📚

一个简单的英语学习网站,适合初中英语水平的学生。

## 功能

**学生端(前台)**

- **账号系统**:访客先注册账号才能使用学习功能(强制登录);登录后导航栏显示用户名,学习进度保存到服务器、按账号隔离,换设备也能接着学;老版本存在浏览器里的进度会在首次登录时自动搬进账号
- 首页:统计概览 + 学习指引
- 单词学习:**按组学习**(默认)——按单词任务的分组从第 1 组开始学,学完一组自动进入下一组,进度与"单词任务"共享;也可切换到**分类学习**复习后台添加的单词(6 个分类),支持键盘 ← → 切换、空格翻面
- 句子测验:看英文句子选中文意思,即时判分;题库 1000 题(适合高考/四级水平),50 题一组共 20 组,支持自选分组练习——**选组测验一轮做完这一整组(50 题),完成后该组自动打 ✓ 标记**;做一半可点**退出本轮**,进度自动保存,下次点进同一组接着做;也可以选"全部随机"抽 10 题快速练习;答错的题可以在结束后**一键重做**;句子里**点击任意单词**即可查看中文释义和音标(自动还原变形);测验成绩按账号保存在服务器,换设备也能看到已完成的小组
- 听力训练:听英文句子(不显示英文),从 4 个中文选项里选出正确意思,难度参考英语四级听力(常速朗读);每题答完后展示**完整听力原文**,可对照原文再听一遍;题库 1000 题(与句子测验不重复),50 题一组共 20 组,选组训练一轮做完一整组,完成后该组打 ✓;也可"全部随机"抽 10 题;答错的题可一键重做;**干扰项按与正确答案的中文实词重叠度挑选**(如"高中生"的选项里会出现"初中生""毕业"),只听一个关键词选不出答案,必须听完整句;发音用浏览器语音合成,无需音频文件
- 课程:小短文阅读(英文原文 + 中文翻译)
- **读单词**:单词卡片、测验、任务里都有 🔊 按钮,用浏览器自带语音合成朗读(无需联网)
- **单词任务**:多词库背词模块,目前两本词库——高考词汇 3877 词(130 组)、大学英语四级真题核心词 2607 词(87 组),每组 30 词,标记"已掌握"记录进度(进度保存在账号里,各词库互不影响);组间没有锁定,没学完也能直接去上一组/下一组;学完的组点进去自动进入**复习模式**(只浏览卡片,不提供取消标记,不影响已学完的进度)
- **三色进度标记**:单词任务和句子测验的分组按钮统一用三种颜色表示进度——白色=还没学,黄色=学了一部分(测验中途退出/单词组掌握了一部分),绿色 ✓=全部完成

**后台管理(/admin)**

- 管理员登录(会话基于签名 Cookie)
- 仪表盘:统计卡片(含注册用户数)+ 分类单词分布 + 最近添加的单词
- 单词管理:搜索、分类筛选、添加、编辑、删除
- 课程管理:添加、编辑、删除
- **用户管理**:查看学生注册的账号(用户名/注册时间/最后登录/已掌握单词数),可禁用/启用账号、重置密码、删除用户

## 技术栈

- 后端:**Python FastAPI** + SQLite + SQLAlchemy
- 前端:Jinja2 模板 + 原生 JavaScript(无前端框架,便于学习)
- 数据库文件 `english.db` 首次启动自动生成,并自动写入 30 个示例单词、3 篇示例课程

## 快速开始

1. 安装依赖:

```bash
pip install -r requirements.txt
```

2. 启动网站:

```bash
python run.py
```

3. 打开浏览器访问:

| 地址 | 说明 |
|---|---|
| http://127.0.0.1:8000 | 学生端首页 |
| http://127.0.0.1:8000/admin | 后台管理登录 |
| http://127.0.0.1:8000/docs | 接口文档(自动生成) |

默认管理员账号:`admin`,密码在 [app/seed.py](app/seed.py) 里配置(首次启动自动创建)

## 常见问题

- **端口被占用**:修改 `run.py` 里的 `port=8000` 为其他端口
- **想重置数据**:停止运行后删除 `english.db`,重新启动会自动重建并写入示例数据
- **修改管理员默认密码**:改 `app/seed.py` 里的默认密码,然后删除 `english.db` 重新启动

## 数据来源说明

任务词库取自开源项目 [qwerty-learner](https://github.com/RealKai42/qwerty-learner) 的公开词典,已转换成本项目格式保存在 `app/data/` 下,可自行编辑替换:

| 词库 | 来源文件 | 词数 |
|---|---|---|
| 高考 3500 词 | GaoKao_3500.json | 3877 |
| 大学英语四级(真题核心词) | CET4_T.json | 2607 |

想新增词库:把词表转成同样的 JSON 格式放进 `app/data/`,再到 `app/task_words.py` 的 `DICTIONARIES` 里加一行配置即可。

句子测验题库来自开放语料库 [Tatoeba](https://tatoeba.org)(CC-BY 2.0),由 `scripts/build_quiz_data.py` 按"英文 5~14 词、中文转简体、单词几乎全部在高考 3500 + 四级词库内"等标准筛选出 1000 句。想重新生成题库:先下载 https://www.manythings.org/anki/cmn-eng.zip 解压为 `_quiz_raw/cmn.txt`,再运行 `python scripts/build_quiz_data.py`。听力题库同源,由 `scripts/build_listening_data.py` 在**排除测验题库已用句子**后另筛 1000 句(偏短句),保证两个模块出题不重复。
